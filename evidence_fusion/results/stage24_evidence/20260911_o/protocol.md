# 源域相对特征结果与目标验证协议

源域相对特征队列正常完成，退出码 0。所有比较为像素监督、源类别留一，三个头部种子，固定骨干与像素采样。

| 方法 | 三种子宏 AUROC 均值 |
|---|---:|
| 原 512 检测器 | 0.96543 |
| 原完整七特征 MLP | 0.98358 |
| 外观分位数相对化 | 0.97640 |
| 外观中位数/MAD 相对化 | 0.97827 |

两种相对化在三个种子下均低于原完整 MLP，配对差值区间全部为负；不能称为源域改进。分位数相对化相对原模型下降约 0.69～0.74 个百分点，中位数/MAD 下降约 0.45～0.60 个百分点。

另一方面，六个模型相对原 512 检测器仍有正增益，2000 次配对区间均高于零：分位数增益约 1.04～1.16 个百分点，中位数/MAD 约 1.17～1.45 个百分点。因此相对化损失了部分源域信息，但并未完全丢失已获得的检测能力。

本轮没有事前设定源域非劣界限，不能将结果称为通过非劣验证。下一步目标评估是一次冻结配置的迁移权衡实验，检验源域损失是否换来泛化收益，不是因为源域主比较成功而扩大实验。
