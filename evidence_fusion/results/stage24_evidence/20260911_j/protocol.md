# 源域局部学习器对照：协议与运行状态

## 目的与监督边界

检验已有局部统计是否能通过普通学习器区分缺陷与非缺陷高响应，从而决定下一阶段优先研究评分还是深层特征适配。本轮是控制实验，不是提出新算法。

使用 VisA 12 类、2162 张官方评估图的图像标签与像素掩码，进行类别外层留一：每次用其余 11 类作为有监督训练数据，只对完全未参与学习器训练的类别推理。每张图只使用其对应留出类别模型的预测计入最终指标。

**这比此前图像标签融合多用了像素监督，不是 VisA 官方纯正常训练协议。** 结果应作为源类别到未见类别的迁移实验单列，不能直接冒充官方无监督 VisA 指标。原骨干和正常内存库保持冻结；各类别原正常校准参数继续使用，属于正常数据适配。AD2 不参与本轮。

所有类别样本可预先缓存，但训练索引按类别排除，代码断言训练图 ID 与被留出类别图 ID 无交集。被留出类别的掩码不参与模型、特征标准化器或参数选择。推理函数没有掩码或标签参数。

## 固定输入与控制

7 个特征：异常响应、局部中心与周围反差、周围响应、周围响应标准差、灰度均值、灰度标准差、图像梯度。特征基于冻结的 512 异常图和原图，不微调 CNN。

控制模型：

- 线性局部分类器，8 个参数。
- 7→32→1 的 ReLU MLP，289 个参数。

两者使用相同特征、样本、像素标签、损失权重、20 轮训练、AdamW 学习率 0.001、权重衰减 0.001、种子 42。MLP 容量更多，比较仅用于判断非线性普通学习器是否有用，不作为新颖性消融。没有搜索隐藏维度、轮数或学习率。

每张异常图最多 32 个缺陷像素，负样本包括最多 32 个高响应非缺陷像素与 32 个随机非缺陷像素。负样本排除缺陷及半径 8 像素的矩形膨胀带。正常图只提供负样本；样本 ID 去重。损失按类别、标签、图像平衡，避免大区域或样本数多的类别支配训练。

特征标准化器只拟合训练类别的采样特征。推理遍历整个 512 网格，以最大 logit 作为图像分数，两个模型一致。未把缺陷区域位置提供给推理，也未使用真值裁剪。

## 验收与解释

自动保存每折模型、标准化器、训练起止损失、训练类别、特征定义和代码哈希。完成后输出逐类 AUROC/AP、宏平均、外层预测和 2000 次配对区间。

主比较是同像素监督下 MLP 对线性模型；同时比较原 512 和固定局部反差控制。相对旧控制的提升混合了额外像素监督因素，不能单独解释为算法贡献。置信区间条件于单随机种子预测，未包含多轮研究选择不确定性。

若普通学习器产生广泛增益，才进一步研究局部校准机制与等监督强控制。若两个学习器都无可靠增益，不继续添加同类统计特征；转而检查深层局部表征。负结果也只能说明本轮特征、训练和固定最大值聚合的局限，不能证明不存在可学习信息。
