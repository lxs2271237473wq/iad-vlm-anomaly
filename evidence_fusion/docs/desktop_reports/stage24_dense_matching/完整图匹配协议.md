# 完整图负样本匹配

复用全部 12 个源类别已有缺陷采样点。对每张异常图，从真实缺陷掩膜经 17×17 膨胀后的排除区之外，枚举所有像素作为负点候选。按原异常响应寻找最近点，允许复用，固定报告 0.01、0.05、0.1 三个正常校准单位的距离上限。

不训练模型；使用已有源类别留一 MLP、种子 42。保存负点在 512×512 图上的坐标、缺陷缓存序号、双方响应及距离。正点原始空间坐标未包含在旧缓存中，因此缓存序号不能当作正点图像坐标。

比较完整候选与上一轮稀疏负点候选的覆盖率、距离和匹配子集配对正确率。正确率仍条件于匹配成功的点及图像，覆盖变化会改变被评估的子集，不能把两个正确率的变化直接称为模型提升。

最近邻查找已内置随机及边界值测试，对照穷举距离最小值。每类完成后保存中间结果。运行目录 results/stage24_evidence/20260912_u。

真实掩膜只用于诊断，不是可部署推理。若完整候选仍缺乏响应重叠，必须报告不可匹配部分；若覆盖改善，再分辨异常图形态和外观贡献。没有目标域评估或新增论文性能结果。
