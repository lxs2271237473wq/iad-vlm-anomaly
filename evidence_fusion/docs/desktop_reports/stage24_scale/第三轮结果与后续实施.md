# 第三轮：候选覆盖、局部评分与高分辨率预检

日期：2026-09-11。服务器运行目录：`results/stage24_evidence/20260911_c`。尺度实验队列正常退出（exit 0）。

## 结论

本轮没有找到优于固定几何融合的可靠新方法。应停止继续堆叠上下文尺度和融合门控，把下一步投入到候选提取与视觉表征的受控验证。当前证据不能支持已经具备 CCF B 级别的方法创新。

## 实验协议

VisA 12 类，共 3026 张正常校准及评估图像，包含 2162 张评估图像。保持 256 分辨率检测器产生的第一候选框不变，比较紧框、1.5 倍和 3 倍上下文的 CLIP 文本分数、正常参考视觉距离，共六个分支。每类正常训练池固定 32 张参考，检索两张参考。校准只使用正常校准图像。

融合采用固定 C=1 的 Logistic 几何控制。外层留一类别评估，内层在其余类别中选择评分分支；因此主结果为 nested_selected，不能用六种分支中事后最优的均值代替。未运行 AD2 新尺度评估，未使用目标标签选择配置。参考图使用 3 倍窗口对齐后裁出子窗口，与上一轮直接裁取参考窗口存在插值差异；查询文本分数进行了旧结果一致性检查，原几何融合 AUROC 完全复现。

|---|---:|

主结果相对几何融合下降 0.00194，配对 bootstrap 95% 区间为 [-0.00423, 0.00023]，仅 4/12 类提升。紧框文本融合的探索性增益为 0.00111，区间 [-0.00175, 0.00394]，不足以认定稳定改善。区间基于固定外层预测、类别及标签分层重采样 2000 次，不包含重训练不确定性，也未作多重比较校正。

视觉正常参考距离比文本独立分支强，但尚未在强融合控制上产生可靠增益。扩大窗口增加覆盖，同时混入更多背景；本轮数据不支持“扩大上下文即可解决问题”。

## 候选覆盖诊断

仅在评分结束后对 1200 张源域异常图使用真值掩码，未用于检索或训练。

| 窗口 | 任意真值交集命中率 | 平均覆盖缺陷比例 | 平均图像面积占比 |
|---|---:|---:|---:|
| 紧框 | 77.58% | 67.78% | 3.36% |
| 1.5 倍 | 78.67% | 71.54% | 7.53% |
| 3 倍 | 83.75% | 78.82% | 27.78% |

命中率仅表示存在交集，并非定位准确率。所有异常掩码在最近邻缩放至 256 和 512 后仍非空；这不能证明 RGB 缺陷细节被保留，也不能排除分辨率瓶颈。

## 512 分辨率实施进度

已在最大源类别 pcb3 的 8 张正常训练图上完成特征提取预检：每图 4096 个、1536 维特征。该类 815 张正常训练图对应原始特征约 19.10 GiB，原 GPU 列表加拼接约需 38.20 GiB，超过当前 23.52 GiB 显存，且尚未计入投影等开销。

已新增 `memory_safe_coreset.py`：原始特征保存在 CPU，分块投影到 GPU，再执行原贪心规则。在 2048×1536 合成特征上，固定种子选择的 204 个索引与原 anomalib 实现完全一致。该测试只证明小规模一致性，尚未接入全量特征提取流程，也未完成 512 内存库训练或异常性能评估。

检查确认当前 anomalib 近邻检索已按 1024 个查询分块，无需误判为完全未分块；仍需测量大内存库时的实际峰值。高分辨率下贪心采样计算量也会明显增加。

## 下一步执行清单

1. 将 CPU 预分配或磁盘映射特征存储接入训练流程，避免列表再拼接造成主存双份占用。
2. 用真实正常特征验证分块投影、采样索引及推理分数一致性，记录显存、主存和采样耗时，再决定全量队列。
3. 在源域进行 256/512 分辨率对照，同时报告固定采样比例和固定内存库预算，区分分辨率收益与额外存储收益。
4. 比较候选覆盖、检测 AUROC、候选后的视觉分支增益；保持数据划分、骨干、种子和校准规则固定。
5. 只有源域出现可复现机制收益后，冻结配置并评估 AD2 全八类；保留朴素融合和几何融合控制。

提高分辨率属于实验与工程改进，本身不构成论文核心创新。只有确认具体失败机制，并提出超越同等计算与监督预算控制的解决方法，才有依据重新判断论文潜力。
