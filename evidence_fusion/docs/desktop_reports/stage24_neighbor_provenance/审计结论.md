# 最近邻来源审计结论

四例全部完成：记忆向量与恢复的正常训练图特征误差均为 0，查询检测分数与历史一致。恢复的是一个精确嵌入来源，不保证重复向量的唯一原始 coreset 索引。

图中红十字是原始特征网格中心，黄框是用于观察的 80 像素窗口，不代表神经网络感受野。绿色轮廓为异常图真实掩膜，仅用于审计。原始网格为 64×64，平滑异常图为 512×512。

## 逐例发现

| 案例 | 观察 | 可支持的有限判断 |
|---|---|---|
| macaroni2 正常 0187，D_z=5.970 | 峰值位于绿色底面上的白色细条；参考为白色小点 | 正常标签下的局部外观变化产生高响应，没有明显跨语义错误对应 |
| macaroni2 异常 028，D_z=-0.086 | 原始中心与平滑峰值均落入缺陷掩膜；参考是正常 macaroni 表面 | 定位到缺陷仍可能图像分数不足，不能仅靠重选峰值解决 |
| capsules 正常 024，D_z=4.007 | 查询与参考均在胶囊边缘、间隙及阴影附近 | 正常几何、阴影差异可能贡献高响应，尚无因果验证 |
| capsules 异常 029，D_z=-1.312 | 原始中心和平滑峰值均不在缺陷掩膜；对应正常胶囊边缘 | 图像最高响应未覆盖该例缺陷，和上一例的失败不同 |

两个异常案例在 512 网格上的缺陷掩膜占比分别约 0.0252%、0.0408%。这支持继续检查微小缺陷的表示能力，但不能据四例认定全部失败都来自分辨率。D_z 是正常校准后的分数，不是概率；未设决策阈值，不把这些样本称为已判定的假阳性/假阴性。

## 决策

当前四例不支持把“错误对应”作为统一原因，不据此训练配准网络或继续改上下文匹配。结论只适用于事后选取的极端案例，不能外推比例。

下一项值得检验的问题是：微小缺陷在保持高空间分辨率的局部重提取下，是否相对正常碎屑、边缘和阴影获得更可分的响应。必须保留普通高分辨率/裁剪重提取控制，不能把放大图片称为创新。

可行的最低成本入口是固定源域候选位置与候选预算，比较原表示和局部重提取表示，首轮直接汇总图像评分；候选产生不使用 GT，并报告漏选缺陷的覆盖上限。若仅靠放大产生收益，归为工程基线；只有额外机制超过等计算预算基线并能独立迁移，才考虑论文贡献。

尚未启动这项新实验。现有审计完成了来源核验与可视化，没有新增有效模型。
