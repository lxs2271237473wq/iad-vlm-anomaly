# 深层邻域对应：首轮结果

384 张图、12 类全部完成，邻域及近邻实现检查通过。没有训练参数，没有使用 AD2。结果为探索性源域子集的图像宏 AUROC。

| 方法 | AUROC |
|---|---:|
| 既有 512 检测器 | 0.963216 |
| 同预算中心近邻 | 0.834310 |
| 邻域匹配中心残差 | 0.788086 |
| 同位置参考 | 0.745768 |
| 打乱对应控制 | 0.469727 |

主比较：邻域匹配减中心近邻 = -0.046224，2000 次配对区间 [-0.075854, -0.018555]，优于中心近邻的类别数为 0/12。不能因超过破坏性打乱控制而声称成功。相比同位置参考的区间跨零；与 512 检测器参考预算不同，但性能仍明显不足。

停止该固定平均邻域对应原型，不扩展到目标域、不搜索邻域大小、分辨率或参考数以追逐正结果。此结果只约束当前 32×32 表示、4 张参考及固定余弦距离，不能证明所有配准或空间关系无效。

方法设计检索已确认配准与上下文比较有明确先例，见同目录《方法重设计与首轮协议》。本轮新增的是可复核的失败证据，不是可支持 CCF B 的算法贡献。

下一轮如要提出新方法，必须先定位一个普通中心近邻实际失败且额外证据能够修正的问题。优先复核 512 检测器的典型误排序及正常最近邻来源是否呈现错误对应，而不是继续凭直觉组合模块。若没有这样的实例与量化覆盖，就不应继续沿对应关系方向投入训练。
