# 失败诊断与外观对照进展

## 已完成的视觉检查

对 AD2 的 can、wallplugs、sheet_metal 和源域 VisA 的 macaroni2，每类选取最高分的 3 张正常图、最低分的 3 张异常图，共 24 张。图板从左到右为原图、真值轮廓、异常图叠加。异常图按每张图独立归一化，不能比较不同图的颜色强弱。

观察：can 的所选高分正常图在反光附近出现强响应；sheet_metal 的微小缺陷难以从纹理响应中分离；wallplugs 的部分所选正常图在物体边缘、背景附近出现响应；macaroni2 的所选高分正常图在小碎屑或背景附近有强响应，部分真值缺陷响应较弱。

以上为极端样本后验诊断，不是总体统计，也不能证明照明是唯一原因。真值只用于选择与标记诊断样本，不参与模型训练。没有据此逐类调节目标参数。

## 已完成的源域正常扰动测试

冻结 512 PatchCore 及内存库；每类按 image_id 取前 4 张正常校准图，12 类共 48 张。分别使用原图、亮度 0.8/1.2 倍、对比度 0.8/1.2 倍，共 240 个视图。原图预测与缓存基线一致性检查全部通过，任务退出码 0。

分数变化除以各类原正常校准尺度（1.4826 MAD；必要时标准差回退），得到以下平均绝对变化：

| 扰动 | 平均绝对变化（正常校准尺度单位） |
|---|---:|
| 亮度 ×0.8 | 0.4912 |
| 亮度 ×1.2 | 1.7297 |
| 对比度 ×0.8 | 0.3393 |
| 对比度 ×1.2 | 1.4611 |

类别间差异很大：chewinggum 四种扰动的平均绝对变化 5.0785，fryum 1.9295，macaroni2 0.4036。这些值受到类别正常尺度大小影响，不是错误概率、AUROC 或跨类绝对异常程度。每类仅 4 张，不能推断总体置信度。PIL 光度变换也不等同于真实照明或反光变化。

本测试证明存在外观敏感性，尚未证明该敏感性造成检测退化，或抑制它就能提高异常排序。它更不能证明所有微小响应都应被去除。

## 已启动的全量控制实验

服务器目录 `results/stage24_evidence/20260911_g`，队列 PID 13017。

使用 VisA 全部 3026 张正常校准和评估图。固定四种光度变换，原图分数复用缓存，首次图像复现检查后每图追加四次推理。正常校准仍只使用正常图，全部评分完成后才读取异常评估标签。AD2 不运行这个探索性分支。

主控制为五视图平均分数对原始 512 分数；中位数、最小值和各单变换均完整记录，避免只保留事后最高结果。每类输出 AUROC/AP，主控制及两个探索性聚合输出 2000 次配对区间。额外推理成本必须计入比较。当前尚无全量效果结论。

它是测试时增强的控制实验，不是新颖方法。如果平均评分不能改善真实源域异常排序，仅正常分数更稳定不构成继续研究的充分证据。如果有改善，后续仍需与已有方法比较，并验证如何保留缺陷证据。

## 文献边界

[SPARC](https://arxiv.org/abs/2608.18585) 已研究用少量正常图像、按空间位置估计子空间投影以去除部署干扰。因此不能仅提出“正常子空间去干扰”便声称首次创新。当前工作的作用是发现可复现失败机制、建立强控制，论文核心方法仍待验证。
