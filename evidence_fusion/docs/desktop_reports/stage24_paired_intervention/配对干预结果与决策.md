# 源域配对干预结果与决策

12 类、96 张图、480 个视图全部完成，原图检测分数、七维特征和 MLP 分数均通过历史结果一致性检查。每类按 image_id 固定选取 4 张正常、4 张异常；使用源类别留一冻结头部，种子 42，没有训练新模型或使用 AD2。

## 结果

下表是该小样本上的类别平均异常—正常配对正确率（等价于该子集宏 AUROC），不是完整 VisA 的性能。每类只有 16 对，配对共享图像，不能当成独立样本。

| 干预 | 检测器 | MLP |
|---|---:|---:|
| 原图 | 0.98958 | 0.97917 |
| 亮度 ×0.8 | 0.98438 | 0.97396 |
| 亮度 ×1.2 | 0.95833 | 0.93750 |
| 对比度 ×0.8 | 0.97917 | 0.96354 |
| 对比度 ×1.2 | 0.95833 | 0.96875 |

亮度增强下 MLP 降幅较大，对比度增强下检测器降幅较大，不存在一致的 MLP 额外退化。所有排序翻转只出现在 cashew、chewinggum；MLP 的翻转全部集中在 chewinggum。其余 10 类没有翻转，既可能较稳定，也可能因小样本及原始排序接近满分而无法揭示问题。

亮度 ×1.2、对比度 ×1.2 的平均新增饱和比例分别为 4.35%、7.00%。实现统计的是 RGB 通道值比例，不是任一通道饱和的像素比例；原图已饱和通道不计入新增。饱和可能改变缺陷可见性，不能直接解释为标签语义保持的照明变化。

48 张异常图上，原图检测器/MLP 的峰值落入缺陷掩膜比例为 79.17%/77.08%；各干预变化方向也不一致。峰值命中不是完整定位指标，不能凭此断言定位更好。

## 决策

暂不启动一致性训练。当前数据没有确认预设的普遍头部敏感性问题；给新损失制造一个假设再用同一测试集挑结果，会削弱论文可信度。

如继续检验此机制，下一步应先改善诊断设计：

1. 固定更温和的配对变换，并在模型评估之前审查新增饱和和缺陷可见性；不能依据预测是否改善筛选图像。
2. 从源域正常校准数据确定低判别间隔的筛选规则，或覆盖完整源域评估集，避免只按前四张 ID 得到接近满分的小样本。若使用源评估标签作分层，必须披露，不能称为未见验证。
3. 对图像级配对变化做区间估计，保留类别结构；不能把 16 对或 512×512 像素当成独立样本放大显著性。
4. 只有重复出现可归因于头部的额外退化，才比较普通增强、普通一致性和拟议新机制，保持监督、模型容量与训练预算一致。没有该证据则停止这条机制路线。

本轮是机制排查的负结果，不能支撑新增算法贡献或 CCF B 水平的声明。原始结果、选择清单和脚本一并保留，便于复核。
