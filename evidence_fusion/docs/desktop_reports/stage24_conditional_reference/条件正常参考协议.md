# 条件正常参考诊断

固定复用完整图响应匹配对。每个源类别使用已有 8 张正常拟合图的均匀及高响应采样点建立参考，去除重复特征向量；另 8 张正常检查图用于描述参考覆盖，不使用目标域记录。

全部七维特征按正常拟合集的中位数/MAD 标准化，MAD 过小时使用标准差及 1e-6 下限。四个比较使用同一参考池：异常图四维最近邻距离、外观三维最近邻距离、七维联合最近邻距离、条件外观距离。条件方法先在四维异常图特征中找固定 32 个近邻，再计算查询外观与这些正常近邻的平均欧氏距离。

使用正常检查点到第 32 个异常图近邻距离的第 95 分位值作为描述性覆盖阈值。分别报告全部匹配对和正负两点都满足阈值的子集，保留覆盖比例。该阈值不是概率保证，不能将超出支持直接解释为异常；高响应与均匀采样混合的比例固定于旧缓存。

三个原响应距离上限 0.01、0.05、0.1 全部保留。不搜索 k、阈值或特征组合。没有重训模型，也不与像素监督 MLP 宣称同监督公平性能竞赛；此轮用于检验正常参考是否有诊断价值。

如果条件方法不能超过无条件外观及普通联合近邻控制，不继续包装该机制。如果覆盖不足，先报告不可识别部分，不能只展示有利子集。即使源域有收益，也必须经过可部署的全图推理评估及独立迁移验证，不能直接称为创新。
