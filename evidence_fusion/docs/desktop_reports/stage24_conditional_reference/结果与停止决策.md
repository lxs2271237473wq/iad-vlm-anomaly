# 条件正常参考：结果与停止决策

12 类、1200 张源域异常图诊断完成，按图像配对重采样 5000 次的分析完成。无新训练，无目标域评估。

严格响应匹配上限 0.01：

| 正常参考得分 | 匹配子集配对正确率 |
|---|---:|
| 异常图近邻 | 54.07% |
| 无条件外观近邻 | 69.07% |
| 七维联合近邻 | 62.45% |
| 条件外观参考 | 59.54% |

条件方法相对无条件外观差值 -9.52 个百分点，95% 配对区间 [-11.87, -7.25]；相对联合近邻 -2.90 个百分点，区间 [-5.07, -0.63]。0.05、0.1 上限呈相同方向。区间是固定参考、固定类别下的探索性图像重采样结果，未校正多重比较或未知场景依赖，不应表述为确认性检验。

满足响应匹配并且两点都在正常参考支持范围内的缺陷点仅占 5.95%（图像再类别均衡），有这类配对的图像为 247/1200。在这一子集中，条件方法 68.03%，仍低于无条件外观 75.72% 和联合近邻 79.22%。这些是不同选择子集的正确率，不能与全部匹配结果直接作性能升降比较。

## 停止决策

固定 32 个异常图近邻后平均外观距离的当前方案，没有超过普通控制，且覆盖有限。停止此实现的参数探索，不选择有利类别、不用 AD2 搜索 k 或阈值。这只否定本次具体方案，不能概括为所有条件参考必然无效。

本轮不是新模型性能实验。69.07% 也不是图像 AUROC，不能据此宣称无条件近邻优于现有检测器。GT 参与匹配，诊断不是实际推理流程。

## 后续工作的优先级

连续诊断已证明：源域完整 MLP 的额外信息真实存在于匹配子集，但绝对外观规则迁移失败；边际归一化、光照一致性动机、当前条件参考都未得到支持。继续在同一七维局部统计上微调不能保证形成论文贡献。

下一阶段应回到可部署的端到端评分验证与方法重设计。最低限度先把无条件正常外观近邻作为普通控制，检验全图推理时是否被背景最大值支配；在源类别留一协议中报告完整图像指标及成本，不以 GT 匹配成绩代替。只有普通控制建立后，才值得研究更丰富的空间结构或正常对应关系，并通过相同预算控制证明新增机制价值。

下一项全图控制尚未启动。需要独立于反复查看的 AD2 的验证数据，且任何 CCF B 目标都必须以实际方法新颖性、强基线及稳定泛化收益为依据。目前仍没有满足这些条件的新增方法。
