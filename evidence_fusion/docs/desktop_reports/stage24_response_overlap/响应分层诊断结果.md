# 响应分层诊断

12 个源类别全部完成。每类用 8 张正常校准拟合图的均匀采样点，按预先固定的 0、50、90、95、99、100 分位点划分响应，并保留上下尾部。复用源域掩膜采样缓存及类别留一冻结 MLP，不训练、不评估 AD2。

有效分层要求正负各至少来自 5 张图。分层内计算按图像均衡的采样像素 AUROC；这里不是全图定位或图像检测 AUROC，也不是严格配对匹配。

## 核心发现

按图像均衡后、再平均类别，70.1% 缺陷采样点、12.2% 负采样点高于正常参考最大响应。99.5% 缺陷点、66.7% 负点落入满足最少图像数量要求的分层。但该“覆盖”只代表粗分层内有两类样本，不代表响应值真正重叠。

每类有效分层平均的 MLP AUROC 均高于原响应，差值范围约 0.060–0.295。该均值对有效分层等权，不同类别有效分层不同，不能当作统一检测性能。尤其无上界尾部很宽，层内仍有响应混杂，不能将差值解释为控制响应后的因果贡献。

## 决策

现在不增添训练模块。优先解决诊断覆盖问题：利用已有正常高响应采样参考细分尾部，并报告正负响应实际重叠与匹配距离；无法匹配的缺陷必须单独报告，不能只保留容易匹配的样本然后宣称普遍有效。层内残余响应可分性也应作为控制报告。

若在足够窄且有支持的响应区间仍有额外信号，下一步再区分异常图形态与外观特征的贡献；必须保持源类别留一，不能根据目标标签选择特征。当前结果尚不足以说明跨域失败原因，更不是论文新方法成果。
