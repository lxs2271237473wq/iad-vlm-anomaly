# Stage24 第二轮：源域双向交换验证

服务器项目：`/root/private_data/iad-vlm-anomaly`，SSH 别名 `iad-vlm-4090`。
第一轮结果：`results/stage24_evidence/20260910_a`。
第二轮结果：`results/stage24_evidence/20260911_b`。
代码：`experiments/stage24_evidence`。旧阶段文件与数据未覆盖。

本轮只在 VisA 源域检验新增证据，不对 AD2 调整新方法或报告新方法结果。

## 已固定的操作

1. 沿用第一轮的完整视野、原图坐标、正常训练/校准隔离和原始分数。
2. 每类别从正常训练图按既有图像 ID 顺序取 32 张组成检索库，排除全部校准/评估图。
3. 查询区域来自检测器 top-1 矩形，不读取真实缺陷掩码。
4. 将匹配输入缩小到 128×128，使用候选周围三倍上下文，最小匹配窗口为 16×16 网格。排除候选矩形及一圈网格，用外围 RGB 平方差做平移搜索，选两张不同参考图。该实现不处理旋转、非刚性对齐，也不声称解决所有参考失配。
5. CLIP 评分窗口保持第一轮的 1.5 倍上下文；参考窗口缩放到同一尺寸。交换矩形内像素，框外保持不变，不进行生成式修复。
6. 每张有效查询编码七个视图：原查询、两个参考、两个候选移除视图、两个候选移入视图。原查询重算用于与旧分数校验；六个新增视图均计入成本，不能称只增加四次编码。
7. 输出移除响应 u、移入响应 v、参考间波动、原查询与参考的文本分数差、视觉特征距离以及匹配误差。正常校准图执行相同操作，用其中位数/MAD校正；这些量不解释为概率或因果效应。

## 学习与对照

采用完整源类别留一验证。每个门控是线性层加 sigmoid，α∈[0,1]，S=D+α(M−D)。固定零权重初始化、α=0.5、Adam 学习率 0.03、150 轮、权重正则 0.01，优化类别等权的类别内成对排序损失。特征标准化仅拟合当前训练类别。未依据 AD2 选择这些参数。

比较仅 D/M/分歧、几何特征、正常参考、单向移除、双向交换、不做正常校准、相同交换视图的简单聚合、打乱交换特征等门控；另比较同特征的 Logistic 模型。几何特征包括候选面积、上下文占比、候选数及回退标记。正常参考对照包含视觉距离，避免把增加参考图像的收益归因于双向交换。

区间使用配对重采样，源域按类别和标签分层，固定本次折外模型。它不包含所有训练随机性，也不代表未知类别/目标域的性能保证。AD2 简单融合的区间另按文件名前缀形成的场景组抽样；该分组仍是物理场景 ID 的代理。

## 继续条件

双向交换需要在折外验证中胜过固定融合、参考门控、参考 Logistic 和同预算聚合，才能支持进一步投入。即使通过，也只是源域机制证据；目标迁移、强分辨率基线、多种子及外部方法比较仍需完成。如果区间跨零或参考对照更好，就保留负结果，先检查候选覆盖和局部表征，不据此宣称创新成立。
