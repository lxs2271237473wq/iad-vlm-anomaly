# Stage24 第二轮实验结果与决策

**结论：当前双向交换实现没有证明额外贡献。保留代码与负结果，暂停向目标域扩展该交换模型。候选几何特征构成了更强、更便宜的对照，后续方法必须超过它。**

本轮在实际服务器 `iad-vlm-4090` 上完成。源域为 VisA 十二类，2,162 张评估图、864 张独立正常校准图，共生成 3,026 组交换证据，全部有效，实际编码 21,182 个视图。每个类别用 32 张正常训练图作参考库，每张查询选择两个参考。校准图与评估图均不进入参考库。

这是一轮已执行的实验，不是预期结果。它尚不能支撑 CCF B 或更高水平的方法贡献。

## 1. 完整基线已经完成

第一轮已完成 AD2 八类 1,084 张 public 图，以及 VisA 十二类。使用完整视野 256×256 PatchCore、224×224 CLIP 视图，保留原始分数，正常训练和校准分开；没有使用目标测试集 min/max。模型、提示、数据清单和分数均保存了来源信息。

| AD2 方法 | 八类宏平均 image-AUROC |
|---|---:|
| 检测器 | 0.668931 |
| 朴素融合，top-1 上下文 CLIP | 0.668585 |
| 源域选择固定权重，α=0.1 | 0.673418 |
| 只用 D/M 的源域 Logistic | 0.677152 |
| 本轮补充的几何特征 Logistic | 0.684130 |

几何特征 Logistic 相对检测器提高 0.015199，但按场景代理分组配对重采样的 95% 区间为 **[-0.016484, 0.047113]**；相对 D/M Logistic 的区间为 **[-0.022150, 0.037717]**。因此，当前不能声称其目标域提升稳定成立。

这些结果与旧四类 243 张缓存的协议和样本集合不同，不能直接比较数值后判断方法变好或变坏。256 分辨率也只是当前基线，不能代表充分调研和验证后的高分辨率强基线。

不能因为双向交换的点估计超过 detector-only，就把提升归因于交换机制。更简单的几何对照已经达到更高的平均结果；交换对参考、同预算聚合和打乱证据均没有获得明确的增量支持。

区间固定本次拟合的折外模型与类别，只反映指定重采样过程；不包含全部训练波动。补充几何 Logistic 是主试验后的诊断对照，其源域结果属于探索性发现，不替代独立确认。

## 3. 已确认的前置瓶颈

AD2 中，top-1 上下文框与真实缺陷至少有一个像素交集的比例：

| 类别 | 异常图命中比例 |
|---|---:|
| can | 2/90，2.22% |
| fabric | 12/90，13.33% |
| fruit_jelly | 50/60，83.33% |
| rice | 17/90，18.89% |
| sheet_metal | 40/90，44.44% |
| vial | 89/105，84.76% |
| wallplugs | 17/90，18.89% |
| walnuts | 56/90，62.22% |

这里的“命中”仅指存在交集，不等于完整覆盖或准确定位。掩码只用于事后诊断，不参加候选选择或模型推理。

源域部分类别的候选覆盖较高，但 CLIP 仍然较弱：例如 candle 的 top-1 上下文框命中 96/100 张异常图，CLIP 图像 AUROC 仍只有 0.5617。因此，需要分别处理候选遗漏与局部表征/语义评分不足，不能把问题全部归因于坐标或分辨率。

## 4. 后续工作顺序

1. **保留几何 Logistic 作为必要强对照。**它使用 D/M、分歧、候选面积、上下文占比、候选数和回退标记，无需交换或额外参考编码；不把这个低成本改进包装成主要创新。
2. **在源域验证输入与候选。**比较更高分辨率或分块输入，训练与推理保持相同尺度；不能直接用 256 训练的记忆库接收 512 输入并称为公平高分辨率复现。记录内存、正常训练覆盖及候选预算。
3. **独立检查局部评分能力。**在相同算法候选上，比较预设上下文尺度、视觉正常参考距离和文本异常评分，源域选参；掩码只诊断候选覆盖，不生成正式模型的裁剪框。
4. **基线形成稳定互补后再设计新增证据。**要求新增信息在折外验证中胜过几何对照和相同预算对照。当前交换模型不进入 AD2 新方法主表，不继续以堆叠门控容量来弥补证据不足。
