# 微小缺陷与正常局部干扰：专项划分与实验方案

## 研究目标与边界

目标是：在固定推理预算和正常误报约束下，区分微小缺陷与高响应正常局部变化。不是只提高 AD2 某两个类别的分数，也不是把所有反光、透明、遮挡问题同时解决。

主协议采用“源域像素监督、目标域仅正常参考”的跨类别迁移设置。它比纯无监督异常检测使用更多监督，必须在论文中明示。不得把已有源域全类别训练过的 MLP 权重用作新类别留出实验的初始化；冻结通用 ImageNet 骨干可复用，新头部从头训练。AD2 异常标签只能用于开发评估。

## 一、数据分层已经如何定义

按原始分辨率二值掩膜做 8 连通区域分解，不删除小连通区域。每个区域分别记录像素面积、占整图比例、边界框及折算到 512×512 后的尺寸。

本项目 v1 的操作性定义：区域面积比例不超过 0.1%，且折算到 512 后边界框最长边不超过 32 像素，记为 compact tiny。它不是通用公认定义，不对应物理毫米尺度。相同面积比例但较长的区域单列为细长/延展小面积缺陷，避免把长划痕和微小点缺陷混为一谈。

图像分成：

| 标记 | 定义 | 用途 |
|---|---|---|
| normal | 正常图 | 所有正常图保留，作为误报分母 |
| tiny_only | 所有缺陷连通区域均为 compact tiny | 主专项图像检测评估 |
| mixed_tiny | 同时有 compact tiny 与其他区域 | 辅助图像评估；微小实例单独定位评价 |
| thin_only | 全部为细长/延展小面积区域 | 单列困难类型 |
| other_anomaly | 其余异常图 | 全量性能与副作用评价 |

主专项不能把 mixed_tiny 的整图判对解释为发现了微小缺陷，因为可能只检测到大缺陷。极小单像素区域可能是标注碎片：先保留并记录，抽查标注质量，不按模型表现删除。主定义冻结；后续可补充面积 0.05%/0.2% 的敏感性表，但不改主定义选最优结果。

正常干扰先用固定 512 检测器标记：正常评估图 D_raw 高于该类正常校准图的第 95 分位，记为 teacher-hard-normal。它是模型依赖的难例标签，不是物理类别，不等于数据标错。保留所有普通正常图；另对难例人工记录碎屑/纹理、边缘/遮挡、反光/阴影、其他/不确定，允许多标签，不确定不能强行分类。

## 二、源域与目标域划分

类别排序由固定字符串 tiny-v1/category 的 SHA256 确定，未按微小缺陷数量或实验成绩挑类别。所有原图不移动、不复制，仅生成清单。

| 用途 | VisA 类别 |
|---|---|
| source_fit，8 类 | pcb2、fryum、chewinggum、pcb4、capsules、pcb3、macaroni2、macaroni1 |
| source_validation，2 类 | pipe_fryum、cashew |
| source_development_holdout，2 类 | pcb1、candle |

这些角色针对原 evaluation 图：source_fit 可用其像素掩膜训练新头部；validation 用于选模型和阈值策略；development_holdout 在配置冻结后报告。已有正常 train/calibration 各自仍用于正常记忆和校准。验证/留出类别正常数据只能按预先固定的正常适配规则使用，不能训练共享头部。

由于这些数据此前都被查看过，development_holdout 不叫独立测试。它提供从现在起的参数隔离，不抹去历史使用。AD2 的 8 类公开测试全部标为 target_public_development，不随机再切一半冒充盲测。同一场景的光照变体不跨角色拆分；scene_group 仍是文件名推断，未获得官方物理身份前不能声称完全排除场景相关。

真正最终验证仍缺失：需要未用于开发的独立数据，或配置冻结后使用官方私有测试评估并限制反复提交。类别是否具有足够微小样本由实际计数决定，不足时应降低结论范围，不能悄悄重划分类别。

## 三、候选创新机制：学会判断局部细节增加是否提供缺陷证据

核心假设：高分辨率既可能恢复缺陷细节，也可能增强正常碎屑、边缘和反光；应学习同一区域在相同视野、不同有效分辨率下的证据变化，而不是把放大后的高分直接判为异常。该假设尚未成立。

### 1. 固定预算的候选提取

先用 512 检测器产生全图粗响应。初始固定每图最多 8 个候选：4 个非极大值抑制后的高响应中心，4 个预先固定网格中心作为覆盖补充。重叠候选确定性去重，空位按固定网格顺序补齐。候选预算与位置对所有控制完全相同，推理不读取 GT。候选窗口初始固定为整图宽高的四分之一，映射回原图提取，不从已经缩小的图中“放大细节”。

提议先作为初始配置在 source_fit 小样本检查运行与覆盖，数值在运行前写入配置；不能因为目标缺陷漏选再调整。若这个预算下微小实例覆盖明显不足，就先解决候选召回，不训练分类头部掩盖漏选。

### 2. 同视野的细节对照

每个原图窗口生成 256 和 512 两个输入，低分辨率输入也回到同一特征坐标系，比较中心及周围的深层特征变化。记录原图窗口本来的像素尺寸，原图不足时不能声称恢复了不存在的细节。

表示包括低分辨率特征、高分辨率特征、对齐后的差异及相应正常参考残差。用小型共享头部预测区域缺陷证据，辅以从正常样本估计的可靠度。首先使用普通拼接 MLP 作为控制，不把多尺度或特征相减本身称为创新。

### 3. 正常干扰对照的学习目标

仅在 source_fit 挖掘粗响应接近的缺陷候选和正常高响应候选；保持普通正常候选以免只学习极端负例。GT 只用于训练时判断候选是否覆盖缺陷，不用于产生位置。边界交叠但覆盖不清晰的候选单独记录，不直接当干净负例。

基础目标为相同监督预算的 BCE。候选机制增加匹配难负例的排序项：L_rank = softplus(m - s_positive + s_hard_normal)。再比较一个“细节贡献”对照：把高分辨率分支替换为对应的低分辨率表示后，判断模型是否仍凭粗分数完成区分。不能强制所有真实缺陷都必须随分辨率提高而增分，也不能强制所有正常区域都不增分；这些单调假设未被证实。

潜在贡献应落在可验证的分辨率证据与正常干扰的分离机制，而不是普通 BCE、排序损失或难负例挖掘。若普通拼接加难例训练已获得相同效果，就没有理由宣称上述机制独立新颖。

### 4. 图像评分与拒绝不可靠证据

局部分数汇总到图像级时，仅使用源验证确定的策略。原检测器分数保留为基础控制。任何门控、融合或置信度都必须在 source_validation 固定，不能使用 AD2 找系数；不把源域 sigmoid 当作跨域校准概率。对无充分正常参考的区域报告不确定性，不能直接据此设高异常分。

## 四、必须打败的控制

| 对照 | 排除的替代解释 |
|---|---|
| 512 原检测器 | 基础性能门槛 |
| 更高全图分辨率、固定滑窗 | 只因更多像素/更多计算 |
| 同候选普通局部重提取 | 只因找准位置后放大 |
| 同候选、同特征、普通拼接 BCE 头 | 只因更强特征和监督 |
| 上述头加普通难负例挖掘 | 只因采样改变 |
| 去掉跨分辨率关系，但保持参数与输入预算 | 关系机制是否必要 |
| 去掉可靠度/门控 | 门控是否只是重新调整阈值 |

比较至少报告像素处理量、骨干调用数、显存、端到端延迟和正常参考容量；相同输入像素量也不保证同延迟。相同 GPU 上按实测成本匹配，不能用更大预算对照声称算法优越。无需一开始把所有模块都实现，按最小控制顺序递进。

## 五、指标与决策

主报告为 tiny_only 异常与全部正常图的类别宏 AUROC、AP，以及正常校准阈值下的检出率和实际正常测试 FPR。不要删掉难正常图来改善指标。图像阈值按 normal_calibration 设置，不能按测试正常分数调阈值后称部署表现；AP 随子集异常比例变化，跨划分不直接比较。

微小区域报告实例召回、区域覆盖和候选召回，并固定每图允许的假阳性区域数。IoU 指标在极小缺陷上敏感，应同时报告覆盖定义，不能只用“峰值命中”。混合异常图中的微小实例单独评价。全量原数据图像 AUROC/AP、定位指标也保留，用于暴露对其他缺陷的副作用。

三个新头部种子，按图像或可靠场景组重采样；不把候选或像素作为独立观测。最低内部继续条件建议冻结为：在源验证上相对等预算局部重提取，tiny_only 宏 AUROC 点估计提高至少 0.02、配对区间下界大于 0，且同校准方案下正常测试 FPR 增量不超过 0.01；样本不足导致区间不稳定时标为证据不足。该门槛是项目资源决策，不是会议接受标准。主要最终指标、门槛及容忍度必须在实际模型选择前锁定。

## 六、相关工作与新颖性边界

[Divide and Conquer（CVPR 2024 Workshop）](https://arxiv.org/abs/2403.04932) 已做高分辨率切块及重叠集成；[HiAD](https://arxiv.org/abs/2508.12931) 也研究高分辨率工业异常检测。因此“高分辨率+裁剪”不能成为核心贡献。

[GLASS（ECCV 2024）](https://arxiv.org/abs/2407.09359) 面向与正常相近的弱缺陷设计全局与局部异常合成；[DeSTSeg（CVPR 2023）](https://openaccess.thecvf.com/content/CVPR2023/html/Zhang_DeSTSeg_Segmentation_Guided_Denoising_Student-Teacher_for_Anomaly_Detection_CVPR_2023_paper.html) 已结合去噪学生与合成掩膜监督。因此弱缺陷、合成样本和分割监督同样不能单独声明为新颖。

本方案的潜在价值是把微小缺陷与真实正常干扰在同预算下联合建模，并检验细节增加的判别价值。尚未完成穷尽检索，也没有证明该机制超过普通多尺度难例学习。定位应是“有证据动机的研究提案”，不是已经确认的新算法。

## 七、执行顺序

1. 完成清单、连通区域统计与角色隔离检查；抽查极小掩膜和正常难例标签。
2. 在固定 source_fit 子样本核验候选覆盖；直接保存无 GT 推理候选，再加载掩膜评估。
3. 先实现等预算普通局部重提取，完整跑图像级评分。如果这一步无收益，先停止复杂头部开发。
4. 有收益后提取两分辨率缓存，依次训练普通头、普通难例头与拟议关系头，保持同一候选。
5. source_validation 决策后冻结，在开发留出类别及 AD2 专项/全量评估；新独立测试另行获取和冻结。

目前完成的是划分工具和方案设计；没有启动新训练，不能报告任何新增性能提升。
