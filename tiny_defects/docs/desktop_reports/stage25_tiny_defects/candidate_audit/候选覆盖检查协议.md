# 候选覆盖检查

使用全部 1462 张 source_fit 图像（8 类），复用已有异常图。完整覆盖检查的成本较低，因此替代小样本抽查；不读取验证、开发留出或 AD2 图像。

每图每种策略固定 8 个窗口，窗口在 512 网格上为 128×128，映射到原图真实区域：top8 为高响应非极大值抑制候选，grid8 为固定网格，mixed8 为前四个高响应候选加四个网格候选。中心抑制半径 64，窗口 IoU 达到 0.5 则去重，按固定 4×4 网格顺序补足预算。边界窗口平移到图内，不缩小窗口。

候选生成函数只接受异常图。所有图的三个策略候选保存为 candidates_no_labels.csv 后，才读取掩膜做覆盖评估。生成器自检包括边界、固定尺寸、候选数、唯一性和重复运行一致性。

原始掩膜上逐连通区域计算最佳单窗口覆盖与窗口并集覆盖。报告单窗口覆盖至少 50%、90% 的微小区域比例；先平均图像内实例，再平均类别，另保留逐实例结果。它们是候选覆盖指标，不是检测召回率。

主方案 mixed8 的资源继续门槛预先固定为：50% 单窗口覆盖的微小区域召回，按图像再类别平均至少 90%。该门槛不是论文接受标准；达到也不代表定位精度达标。未达到则先分析候选漏选，不启动复杂头部训练。top8、grid8 仅作固定预算对照，不根据目标数据换策略。

运行目录 results/stage25_tiny_defects/candidate_v1。当前只进行覆盖检查，不训练新模型。完成后才能决定局部重提取是否具备候选覆盖基础。
