# 新一轮：直接监督局部深层特征

停止两分数融合调参，转为学习局部缺陷表示。此次是直接训练的监督基线，不预先声明算法创新。

使用固定 source_fit 的 1462 图训练，source_validation 的 cashew、pipe_fryum 共 300 图评价。没有 AD2、开发留出异常参与训练。冻结 WRN50_2，输入为原图 quarter-field 候选裁剪后 256 像素；使用 layer1 和 layer2，后者上采样至前者，形成 64×64×768 局部特征。不同于此前七项手工统计。

沿用已保存的 mixed8 候选算法，先对训练和验证所有图生成并保存无标签候选，再访问训练掩膜。每个窗口最多抽取 16 个缺陷网格、16 个原检测器高响应负网格及16个随机负网格。掩膜面积投影到 64 网格后非零即正，负例排除一格膨胀带；该规则避免丢失极小标注，但可能产生部分覆盖标签噪声，需在解释中披露。

相同样本、标准化与 BCE 训练预算：768→1 线性头，对比 768→64→1 的 ReLU MLP。AdamW lr=0.001、weight_decay=0.001，20 epoch，batch=4096，种子42/123/2026；按类别、正负标签和图像均衡采样权重。比较三种子全部结果，不选最高种子。

验证逐窗口全网格预测，最大局部 logit 再取八窗口最大值作为图像分数，不用验证掩膜选点。全部验证预测存盘后计算全量及 tiny_only+全部正常的 AUROC/AP，比较原检测器和同种子线性头。

主问题：更丰富的局部表示加相同监督下的非线性判别，是否能在未用于拟合的类别改善图像检测？这是普通基线，若线性已解释收益，不把 MLP 增加当创新。若全部方案低于原检测器，不进入 AD2，不追加注意力或融合模块。

候选覆盖不代表检测成功；源验证只有两类、部分样本及历史使用限制仍在。新监督强于无监督 PatchCore，需同时比较同监督线性头。正常 FPR、等成本和完整独立泛化尚需后续检验，不能凭一次 AUROC 提升宣称达到论文标准。
