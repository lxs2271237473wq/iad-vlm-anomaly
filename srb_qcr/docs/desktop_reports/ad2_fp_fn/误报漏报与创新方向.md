# PatchCore 512：误报、漏报与创新方向

本轮只读取已有预测、计算统计和检索论文，没有恢复 GPU 训练。

## 统计协议

AD2 public 八类 1084 张：379 张正常、705 张异常。302 张校准图的 image_id 已全部与既有 manifest 对齐，来自 validation/good。每类用其正常校准分数的经验第 95 百分位（numpy quantile higher）确定阈值，预测分数严格大于阈值时报警。没有根据 public 标签调阈值。这是新建诊断操作点，不是历史已部署阈值。

每类校准样本仅 19～48 张，第 95 百分位在尾部不稳定；正常条件变化下更不能保证测试误报率为 5%。结果为图像级统计，不是像素级统计。多条件图像并非独立物体，当前比例按图像计数，未提供独立样本置信区间。

| 真实/预测 | 判为正常 | 判为异常 |
|---|---:|---:|
| 正常 | TN=309 | FP=70 |
| 异常 | FN=392 | TP=313 |

- FPR=FP/(FP+TN)=18.47%；FNR=FN/(FN+TP)=55.60%。
- 462 次错误中，FP 占 15.15%，FN 占 84.85%。
- 全部 1084 张图中，FP 占 6.46%，FN 占 36.16%。
- 类别宏 FPR=15.76%，宏 FNR=57.00%，不同于以上样本汇总比率。

完整逐类结果见 category_confusion.csv，逐图判定见 predictions_q95.csv。q90/q95/q99 敏感性见 summary.json：FPR 分别 29.29%/18.47%/8.71%，FNR 分别 40.71%/55.60%/70.07%。单纯提高阈值会减少 FP，同时增加 FN。

作为另一项仅用于评估的 ROC 诊断，每类召回至少达到 95% 时，宏 FPR 为 74.95%；can 为 98.61%，wallplugs 为 90.00%，sheet_metal 为 87.50%。此处阈值使用测试标签构造 ROC，不能拿来部署或调参。结果说明当前分数排序在高召回区域仍有严重重叠，而不只是阈值偏移。

## 是否值得研究低 FP

值得，但应定义为“正常局部干扰下，在保留微小缺陷召回的同时降低误报”，不能只展示某阈值的 FP 减少。优先指标：图像 FPR@95%TPR、低 FPR 区间 partial AUROC、冻结正常校准阈值下的 FPR 和 FNR；像素级单独报告 AU-PRO@0.05、正常图报警区域数量/面积及微小缺陷召回。

## 文献边界

- FAI 已使用正常训练图像学习潜在误报语义，采用 MLP 二阶段过滤，因此“挖正常高分块+MLP消误报”不是新的核心贡献：https://pubmed.ncbi.nlm.nih.gov/38067730/
- SubspaceAD 已使用正常特征 PCA 子空间重建残差：https://clendering.github.io/SubspaceAD/
- SPARC 已研究少量正常部署图像下的位置子空间校准：https://arxiv.org/abs/2608.18585
- PNI 已研究位置和邻域信息：https://arxiv.org/abs/2211.12634

这是一轮针对性检索，不是完成的系统文献排重。仅调阈值、加 PCA、加邻域检索或加 MLP，当前不足以构成所需的新颖性。

## 建议验证的具体假设

在正常干扰背景上，同一位置加入微小结构破坏，学习二者的差异响应：降低对原有干扰的响应，同时维持对新增破坏的敏感性。候选方向是“保留缺陷响应的正常干扰消除”，目前是待验证研究假设，不能称为已经成立的新方法。

1. 从正常训练集按物体分组交叉留出，建立不含查询物体的参考库，挖掘高分正常局部区域。避免用自身近邻制造虚假低误报。
2. 在相同正常背景、相同位置构造未破坏/微小结构破坏的配对样本。局部位移、边缘断裂、细裂纹等操作必须检查合成伪迹；至少留出一类合成算子验证泛化。合成表现不替代真实缺陷表现。
3. 用共享的小型特征适配器学习成对排序约束：原有干扰应低分，新增缺陷应高分；同时加入缺陷响应保留约束，避免学成普遍压分器。固定骨干，先在缓存特征上验证，计算量较低。
4. 如果抑制依赖正常参考，则仅在参考支持足够时抑制；支持不足回退到基线。支持判定也必须通过真实缺陷召回验证，不能凭启发式声称安全。
5. 与调阈值、FAI 式 MLP、普通难负样本挖掘、普通合成异常训练、PCA/SPARC 类校准分别比较。项目已有邻域检索、局部 MLP、合成修复负结果，必须说明本假设为何不同；若配对约束不能比普通训练多带来收益，就停止此路线。

## 进入长训练前的门槛

先对错误样本做分层审查，区分表征未响应、局部干扰过强、缩放丢失、图像汇总问题，不预设照明是主因。全部八类报告，重点困难类只作分析。图像级和像素级分开，不按 public 标签挑类别和配置。

可预注册内部继续门槛：固定至少 95% 召回时 FPR 相对下降至少 20%，且不是由单类别驱动；微小缺陷召回不出现有意义的下降。此数字是资源决策目标，不是会议门槛或保证。还需要多种子/物体分组区间、第二检测器、至少另一数据集和未用于调参的评估。最终能否达到 CCF B，取决于机制与相邻工作有明确差异、优势可重复、召回代价可控，而不是把主指标换成 FPR。
