# 历史 AD 模型在 AD2 上的结果复核

2026-09-15。已停止 RoBiS 与 ISVL 训练队列，保留已有权重，本轮没有训练新模型。

## 早期四类别实验

类别为 fruit_jelly、sheet_metal、vial、walnuts。历史主线缓存为 243 张；下表取服务器历史结果文件，并非本轮重新推理。各外部方法逐样本集合仍需重新对齐验证，因此这是历史成绩盘点，不是已重新核验全部协议的公平排行榜。

| 方法 | 宏图像 AUROC |
|---|---:|
| PatchCore | 78.53% |
| EfficientAD 30 epochs | 76.04% |
| EfficientAD 100 epochs | 76.57% |
| WinCLIP，固定 1-shot 协议 | 61.38% |
| AnomalyCLIP，固定官方 checkpoint | 53.90% |
| PatchCore + context VLM，LOCO | 82.10% |

EfficientAD 延长训练：图像 AUROC 仅增加 0.52 个百分点，1/4 类改善；像素 AUROC 从 80.93% 增至 83.46%，4/4 类改善。说明图像判别和像素定位的趋势不同。

同集调参融合 84.53% 仅是诊断上界，不列为正式收益。另一个后期历史 SRB 缓存的朴素融合为 82.86%、SRB 为 79.39%，它使用的分支与早期 context VLM 不完全相同，不应拼为一个实验。

来源见本目录从服务器保存的三个原始 CSV。老四类缓存还有历史目标集全体 min-max 归一化、流程版本与裁剪可复现性问题，具体见既有项目审计报告。

## 后续完整八类别实验

1084 张 public 图，本轮从逐样本预测独立重算 PatchCore 两种分辨率的逐类 AUROC 和宏平均，结果与报告一致。

| 方法 | 宏图像 AUROC | 宏图像 AP |
|---|---:|---:|
| PatchCore 256 | 66.89% | 79.08% |
| PatchCore 512 | 73.14% | 83.00% |
| DINOv2 近邻，max 汇总 | 72.16% | 81.84% |
| DINOv2 近邻，top1 汇总 | 72.21% | 82.18% |
| 源域冻结 PatchCore + DINOv2 分数融合 | 75.83% | 84.05% |
| PatchCore 512 + 朴素 CLIP 融合 | 66.97% | 80.48% |

PatchCore 配置：wide_resnet50_2、layer2/layer3、9 邻居、全视野方形缩放，无中心裁剪。512 实验沿用固定内存库预算与源域冻结设置，不能解释为新方法贡献。

| 类别 | PatchCore 256 | PatchCore 512 |
|---|---:|---:|
| can | 44.38% | 51.54% |
| fabric | 71.03% | 78.57% |
| fruit_jelly | 79.00% | 92.42% |
| rice | 53.36% | 68.12% |
| sheet_metal | 69.95% | 65.32% |
| vial | 86.42% | 86.88% |
| wallplugs | 46.52% | 56.26% |
| walnuts | 84.48% | 86.04% |

独立重算结果：`recomputed_patchcore_8class.csv`。PatchCore + DINOv2 冻结融合的既有场景分组区间为 AUROC 差值 +2.69 个百分点，95% 区间 [-0.43,+5.95]，跨零；tiny_only 子集从 67.09% 降到 65.56%，没有证明微小缺陷专项收益。

## 判断与下一步

1. 当前完整八类已验证的通用 AD 模型基线以 PatchCore 512 为起点，比直接使用旧四类结果更适合重新分析。
2. 优先审查 can、wallplugs、sheet_metal 的错误样本和像素异常图。低图像 AUROC 既可能来自局部表征，也可能来自异常图到图像分数的汇总；不能预先断定是照明。
3. 用已保存异常图检查：异常区域是否响应、正常干扰是否抢占最大分数、缺陷是否因缩放消失；先确定错误环节，再决定是否需要训练。
4. 现有结果没有支持“继续堆分数融合”或“训练越久越好”。图像 AUROC、像素 AUROC、AU-PRO@0.05 必须分表，不能混用。
5. 本次没有找到 FastFlow 的 AD2 成绩，其已确认结果为 VisA；未发现可供引用的 GLASS AD2 结果表。仓库中有模型代码不等于已完成 AD2 实验。
6. public 已反复用于开发，后续提升不能当作未经选择的盲测结论。
