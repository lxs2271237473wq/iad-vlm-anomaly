**AD2 主实验方案｜2026-09-10**

按用户最新要求，主实验改为 MVTec AD 2 完整八类。VisA 用于融合策略开发，MVTec AD 用于补充迁移和强检测器条件下的稳健性验证。首要目标仍是新融合在检测精度上超过朴素融合和强简单融合；选择性调用排在后面。

本文是执行方案；本次完成了仓库清单核算，没有重新运行检测器、VLM 或融合训练。历史缓存的几何和校准问题尚未因换数据集而消失。

**为什么改主数据集，同时必须改方法**

AD2 包含透明物体、反光、物体重叠、正常外观变化及微小缺陷，更适合研究复杂条件下两分支的互补性。原论文讨论的旧基准饱和主要涉及分割 AU-PRO，不能把该结论直接当作本项目图像 AUROC 的证据。[官方介绍](https://www.mvtec.com/research-teaching/datasets/mvtec-ad-2)、[数据集原论文](https://arxiv.org/html/2503.21622v1)

本项目已经有直接依据：MVTec AD 缓存检测器 macro image-AUROC 为 0.9882，接近饱和；VisA 两个检测器约为 0.9138 和 0.8934，并非所有现有设置都已接近满分。AD2 旧四类、243 张图的同清单缓存结果如下：

| 方法 | macro image-AUROC |
|---|---:|
| 检测器 D | 0.7853 |
| VLM M | 0.6524 |
| 朴素融合 | 0.8286 |
| 原 SRB | 0.7939 |

朴素融合比 D 高 4.33 个百分点，SRB 比朴素融合低 3.47 个百分点。这支持“已有互补信息未被 SRB 保留”的判断。它不证明新方法必然有效，也不能作为完整 AD2 八类成绩。数据来自本次审计重新计算的历史缓存，见 audit_data/srb_component_ablation.csv；修复后必须重跑。

**先补足视觉证据，再判断融合价值**

1. 修复坐标链：记录原图尺寸、resize、padding、crop、tile 的映射；从原图按正确坐标取候选区域。正常与异常样例、图像边界、非正方形图必须覆盖几何检查。
2. 保留全视野：AD2 含边缘缺陷，默认中心裁剪会删除真实证据。采用保留长宽比的缩放加 padding，或覆盖完整图像的切块；具体分辨率、重叠和聚合规则在源域确定并锁定。
3. 建立分辨率对照：先运行完整视野基础分辨率，再增加一种高分辨率/切块设置。更高分辨率不仅给新方法使用，也给 detector-only、朴素融合和简单学习融合使用，区分视觉信息增加与融合机制的收益。
4. VLM 使用“全局上下文＋原图局部细节”，不把整幅高分辨率图直接缩到 224 后再裁局部。先评估固定数量候选、不同上下文范围和正常参考是否有用，不预设三者全部组成最终模型。
5. 候选只由检测器或预先规定的网格生成；异常掩码仅用于离线诊断。若候选覆盖不到真实缺陷，先修复候选召回；如果覆盖了但 VLM 仍失效，再研究提示、参考和融合。

反光或光照变化会同时误导检测器与 VLM，微小缺陷也可能对两者都不可见。因此 AD2 提供了研究空间，不提供融合增益保证。正常参考必须来自允许使用的正常集；未知光照的测试图不能被拿来建立参考库而仍称相同部署条件。

**融合改动保持精度优先**

旧 SRB 保留作对照，取消其固定检测器主导、质量连乘和分歧必然压低 VLM 的默认设计。先对全部图像执行同一 VLM 管线，研究：

α(x)=sigmoid(hφ(rD(x),rM(x)))，S(x)=(1−α(x))d(x)+α(x)m(x)。

d、m 是按统一、固定规则校准的分支分数。α 允许取遍 0 到 1；初始化为 0.5 时退化成同尺度朴素融合。优先用线性小模型，rD/rM 候选包括候选稳定性、区域与背景对比、正常参考支持及提示证据稳定性。它们都是待验证特征，不把“稳定”直接定义为“正确”。源域按类别等权的排序损失与简单分类损失做有控制的比较；完整训练细节见《精度优先的融合改造方案.md》。

校准变换由源域确定规则，目标域只允许按该规则使用独立正常 validation。禁止读取目标全测试分数的 min/max。各类 validation 仅 19–48 张，避免强裁剪或粗粒度经验 CDF 把异常分数压成大量同分；报告校准敏感性。正常数据只能提供正常分布信息，不能直接估计目标异常检出可靠性。

**必须同时跑的主对照**

| 编号 | 方法 | 要排除的解释 |
|---|---|---|
| B0 | detector-only | 新系统是否损害强检测器 |
| B1 | VLM-only | 第二分支本身是否有用 |
| B2 | α=0.5 朴素融合 | 最直接的用户验收基线 |
| B3 | 源域选择固定 α，搜索包括 0 和 1 | 是否只是换一个常数权重 |
| B4 | 简单线性/单调分数融合 | 是否只是多用了源域标签 |
| B5 | 原 SRB | 与历史方法衔接 |
| B6 | 新相对可靠性融合 | 候选方法的独立收益 |

主检测器用正确复现的 PatchCore，第二检测器用项目已有的 FastFlow。若其复现明显落后于合理配置，先排查而非直接利用低分；后续增加一种有官方实现的强检测器检验通用性。AnomalyCLIP 等独立 VLM 基线重新在同一 1,084 张图上计算，不沿用此前 484 张与 243 张混比。

B0–B6 共享图像清单、检测器与 VLM 原始输出、校准制度和可见监督。新方法额外使用可靠性特征时，再补充“简单融合＋同样特征”，排除提升仅来自额外输入信息。旧 SRB 在新管线上的成绩应标记为重新评测，不能假设仍等于历史缓存数字。

**统计与论文证据**

主指标是八类等权的 image-AUROC；同时报告每类、image-AP、预定阈值下误报/漏检，以及常规光照和变化光照的表现。AUROC 不等同固定阈值检测准确率；不要混用名称。需要解释机制时，按缺陷大小、边缘位置、光照类型分析纠错与引入错误，分组规则提前固定，掩码不进入推理。

public 中存在同一场景的多个光照版本。根据仓库的“类别＋good/bad＋数字文件名前缀”可得到 184 个候选场景组；实际场景对应还应对照官方元数据或图像确认。配对 bootstrap 应在类别内按正常/异常场景分层抽样，保持同一场景所有光照版本及所有方法一起重采样；随机训练种子另行报告，不能把重复光照图当作独立样本夸大显著性。

如果方法仅输出图像分数，论文贡献先限定为图像级检测。AD2 官方服务的异常图提交和像素指标不能自动证明图像级融合提升；接入前核对服务支持的输出及返回指标。只有真正实现并验证像素级输出后，才将 AU-PRO 等作为新方法定位能力的证据。[官方评测入口](https://benchmark.mvtec.com/)

接受条件：预先指定新方法相对 B2、B3、B4 的 macro image-AUROC 差值及配对区间；至少在两个可靠检测器上检查收益和类别退化。不能只击败原 SRB，也不能为了击败差的平均融合而接受明显差于 B0。若证据仍无法稳定胜过强简单融合，先改视觉证据或换模型假设，暂停效率模块扩展。

更换基准本身不构成 CCF B 论文贡献。更有价值的待验证主张是：在复杂光照、反光和微小缺陷条件下，能够识别两分支何时提供有效纠错，并使这种判断跨类别、跨检测器迁移。是否达到投稿竞争力，要由相应结果和相对已有工作的差异证明。

**4090 / A800 上的执行顺序**

1. CPU 阶段：冻结完整八类清单，确认 train/validation 分离，修复几何、校准与运行版本记录。先让单批图像端到端复现。
2. GPU 阶段：以一个检测器完整跑八类，所有样本执行 VLM，缓存原始分数、正确 ROI 和可靠性特征；先拿到 B0–B5。再跑第二检测器。不同时打开多个大模型，按显存设批量。
3. 学习阶段：先在源 VisA 选择融合结构，复用缓存训练小融合器及强简单基线，锁定参数后评测 AD2。
4. 确认阶段：完整方法做多个随机种子，增加 MVTec AD 补充迁移，按支持的任务接入隐藏测试；只有精度结论成立，才研究少调用 VLM。

当前没有基于这些新设置的实测速率，因此不承诺固定 GPU 小时数。4090 的 24 GB 或不同显存规格的 A800 都应先实测预处理、显存峰值和每图推理时间，再排完整任务。缓存会让后续融合消融主要发生在小模型侧。
