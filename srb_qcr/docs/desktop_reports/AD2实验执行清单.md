- [ ] **A02｜创建独立实验目录。**新建 Stage24 的代码、缓存、模型和结果目录；固定仓库提交。验收：旧 results、runs 和适配数据目录均不会被新脚本覆盖。旧 Stage11 适配器含递归删除目录操作，不直接重跑该入口。
- [ ] **A03｜复用并锁定可用环境。**优先核对服务器原环境，确认 PyTorch/torchvision/anomalib/CLIP 后端的兼容性；缺失时建立单独环境。固定一种 CLIP 后端及权重，不在运行失败时静默切换。产物：`environment.txt`、`weights_manifest.json`、单批 GPU 推理日志；权重记录版本与哈希。

验收点 A：数据与模型真实可读，单批推理成功，输出路径独立。环境检查通过并不等于模型已完成训练。

**B．修复数据划分、几何与校准**

- [ ] **B01｜建立真实文件清单。**读取八类原图，校验文件存在、图像可解码、数量与标签对应，检查重复。保留 official train/validation/test_public。产物：`manifest.csv`、`data_validation.json`。验收：2,528/302/1,084 张完整；异常掩码只用于评测与离线诊断。
- [ ] **B02｜记录场景与光照分组。**根据官方元数据或图像确认多光照场景对应；数字文件名前缀推得的 184 组仅作候选映射。产物：`scene_groups.csv`。验收：同一场景不同光照不会跨融合训练与验证划分，统计重采样也保持成组。
- [ ] **B03｜修复所有坐标转换。**显式记录原图尺寸、缩放、padding、裁剪和切块的变换；用原图坐标生成局部图。产物：几何检查结果、带框可视化。验收：合成已知位置测试通过；非正方形、边缘区域、灰度输入及实际样例均无错位、空框或越界。
- [ ] **B04｜固定完整视野预处理。**取消不合理中心裁剪，建立保留长宽比的完整图输入；另设一种高分辨率/切块对照。分辨率、重叠率、分数聚合与候选数只在源数据选择。产物：`preprocess_config.yaml`。验收：检测器和各融合对照获得相同视觉输入条件。
- [ ] **B05｜隔离正常校准与测试评测。**检测器只用允许的正常训练图；官方正常 validation 独立保留。显式配置后处理，核实它不会从 test 标签学习阈值。D/M 尺度映射规则由源域确定，目标只按规则使用正常 validation；禁止全测试 min/max。产物：`calibration.json`。验收：评测阶段不重新拟合映射，删除测试标签不改变预测分数。
- [ ] **B06｜运行固定小批量端到端检查。**每类固定取 2 张 train、2 张 validation、4 张 public，共 64 张，按样本 ID 选取并保存清单。执行读取→检测器→候选→CLIP→融合→输出。产物：`smoke_predictions.csv`、裁剪预览、耗时/显存日志。验收：分数有限、数量齐全、无未解释回退；不按这 64 张目标图的 AUROC 调参。

验收点 B：划分独立、几何正确、校准冻结、小批量可复现。失败时修复对应环节，不进入全量实验。

**C．重建完整分支预测与强简单基线**

- [ ] **C01｜运行 PatchCore 基线。**先按新协议完整跑 AD2 八类，保存模型与原始异常图/分数；避免候选阶段重复训练检测器。产物：`detector_predictions.csv`、模型检查点、训练日志。验收：public 每张图恰有一个图像分数，低分首先排查训练和预处理。
- [ ] **C02｜全量运行 CLIP 分支。**每张图保留全局分数，并按固定规则提取原图局部候选；记录紧框、上下文框与各自分数。输入无有效局部候选时按固定规则使用全局分支，不静默删除样本。产物：`vlm_predictions.csv`、ROI 清单、提示模板及版本。验收：全部 1,084 张均纳入评测，所有失败/回退均可追踪。
- [ ] **C03｜在源 VisA 重建同定义缓存。**使用同一预处理、候选、CLIP 后端及质量特征定义。保存原始 D/M 与正常校准结果，不能将语义不同的旧 Q 直接拼接训练。产物：`source_features.csv`、`feature_schema.json`。
- [ ] **C04｜建立源域验证折。**按类别划分融合训练与验证；同一图像、物件及其多个检测器输出保持同组。融合超参数采用源域内部验证；需要调参时使用内外层划分。产物：`source_folds.json`。验收：报告折外指标，不把训练集拟合 AUROC 当作泛化成绩。
- [ ] **C05｜运行下表 B0–B5。**固定权重网格先用 0、0.1、…、1，所有权重和简单学习模型参数仅在源域选择。旧 SRB 在修正管线下重评估，明确记录与历史 Q 定义或校准的差异。产物：`baseline_metrics.csv`、逐图预测及逐类别表。

| 编号 | 必跑方法 | 作用 |
|---|---|---|
| B0 | detector-only | 强检测器参照 |
| B1 | CLIP-only | 判断第二分支质量 |
| B2 | 0.5D＋0.5M | 朴素融合主参照 |
| B3 | 源域选择的固定权重 | 排除只是换一个常数 |
| B4 | 简单线性/单调分数融合 | 排除只是多用了源域监督 |
| B5 | 修正管线下的原 SRB 规则 | 与历史方法衔接 |
| B6 | 新证据驱动融合 | 待验证的新方法 |
| B7 | 同证据特征的简单融合器 | 区分特征与模型结构贡献 |
| B8 | 相同额外视图预算的普通聚合/一致性方法 | 排除额外推理次数的贡献 |

验收点 C：获得可追溯的完整八类基线，并确认源域两分支存在可利用的互补信息。首次 AD2 基线成绩可以报告，但不据此选择新方法超参数；当前 AD2 已被查看，不称完全未见测试。

**D．先验证“证据有用”，再扩大融合模型**

- [ ] **D01｜写清与已有工作的差异。**对照 WinCLIP、MoXpert、InCTRL、TC-MAF 及一致性可靠性方法，明确本研究只主张待验证的“受控局部证据用于预测纠错价值”。产物：一页 `novelty_comparison.md`。验收：不把多尺度、正常参考、动态门控或改用 AD2 单独写成首创。
- [ ] **D02｜实现最小成对证据视图。**从算法候选生成“处理候选区域”和“处理匹配对照区域”两种图；约束面积、形状、处理方式及上下文尽量可比。第一版固定一种处理操作，先只给 CLIP 增加两类视图。产物：干预清单、原图/两视图示例。验收：区域完全由推理信息确定，不使用测试掩码；没有可比对照时记录缺失标志与固定处理规则。
- [ ] **D03｜量化操作本身的伪影。**在独立正常图上运行同样的区域选择与处理，统计分数漂移；校准规则在源域确定。产物：`normal_intervention_stats.json`、漂移分布图。验收：检查遮挡边缘、物体语义和位置差异是否主导响应；无法区分伪影时先修改证据设计。
- [ ] **D04｜生成统一证据特征。**保存原图分数、候选处理分数、对照处理分数、两者差异、有效性标志及预先规定的上下文信息。产物：`evidence_features.csv`、字段说明。验收：源/目标定义一致，推理特征不含 Y、掩码面积、异常文件夹标记或其他标签衍生字段。
- [ ] **D05｜检验源域折外纠错信号。**在源域内分析这些特征是否能预测相对朴素融合的排序改善，并与原始 D/M、普通置信度和一致性特征比较。正负样本对只在类别内构建；“纠正排序”与“破坏排序”分别统计。产物：折外增益表、纠错/误伤分组图。验收：效应可重复且不只来自训练拟合；“稳定”不能直接被定义为“正确”。

验收点 D：若源域折外看不到可重复的额外信号，暂停扩大门控网络，先修正局部证据或候选提取。此时不把随机微小收益当作继续堆模块的理由。

**E．训练、比较并冻结新融合器**

- [ ] **E01｜实现最小融合器。**先使用线性小门控，输入统一证据特征，α∈[0,1]，输出 S=(1−α)d＋αm，初始化 α=0.5。不使用旧 SRB 的固定 0.35 上限与分歧连乘衰减。产物：`train_fusion.py`、模型权重及模型配置。
- [ ] **E02｜训练源域排序目标。**类别等权、类别内构造正负对；固定小范围的正则和温度候选，在源域验证选择。分别记录排序改善与破坏，并检查极端分数、饱和权重和非单调响应。产物：源域验证结果与超参数选择记录。验收：融合器选择过程不访问 AD2 异常标签。
- [ ] **E03｜完成 B7/B8 及关键消融。**至少包括：去掉成对对照、去掉正常漂移校准、打乱证据特征、同特征简单模型、同额外视图预算的一般聚合/一致性方法。保持分辨率、候选、参考和监督一致。产物：`source_ablation_metrics.csv`。
- [ ] **E04｜冻结最终配置。**确定一套主方法及预先列出的对照、种子、指标、分组和推理失败规则；保存代码提交、模型/配置/输入清单哈希。产物：`frozen_protocol.json`。验收：之后的 AD2 结果只用于评估；若因结果再改方法，记录为新开发轮次并重新安排独立验证。

验收点 E：新方法在源域折外优于有竞争力的简单方法，且机制消融支持设计作用；否则先返回 D，不投入大规模目标重复实验。

**F．完成足以判断论文价值的实验**

- [ ] **F01｜运行冻结的 AD2 八类主表。**在相同 1,084 张图上评测 B0–B8，输出逐图、逐类和八类等权 macro image-AUROC，并报告 image-AP。补充在预先规定阈值下的实际误报/漏检；不把 AUROC 称为固定阈值准确率。产物：`main_results.csv`。
- [ ] **F02｜报告不确定性。**主方案使用 3 个预先固定的随机种子；随机性来自检测器/参考采样时也应覆盖相应环节。按类别及正常/异常场景分层，配对重采样场景组计算方法差值的 95% 区间；保持同场景各光照和各方法一起抽样。产物：`paired_intervals.csv`、种子结果。验收：种子波动与场景抽样不确定性分开报告，不用重复光照夸大样本量。
- [ ] **F03｜检查光照和错误来源。**报告 regular 与变化光照结果；使用掩码仅在评测侧分析边缘/小缺陷等固定分组；展示纠错与误伤案例。产物：`failure_analysis.csv`、图像案例。验收：解释对应真实预测，完整保留失败类别。
- [ ] **F04｜更换检测器验证。**增加正确复现的 FastFlow，保持规则一致，并在源验证时检查留出检测器的迁移。若某检测器明显低于合理复现，先排查。产物：第二检测器主表及运行记录。验收：收益不是通过人为削弱检测器获得。
- [ ] **F05｜补充 MVTec AD 迁移。**冻结源训练得到的融合器；允许相同协议下的目标正常训练与校准，检查强 detector-only 条件下的退化。产物：迁移结果表。验收：不以超过表现较差的平均融合掩盖对强检测器的明显损害。
- [ ] **F06｜核对外部方法与隐藏评测。**AnomalyCLIP 等相关方法使用同一 public 清单并披露监督/分辨率/参考预算差异；选择需要复现的最相关方法，不能仅有内部消融。核对 AD2 官方服务支持的任务与输出；只输出图像分数时，不用服务器像素指标冒充图像级融合证据。产物：公平比较表、隐藏评测可行性记录；支持时再执行冻结后的提交。

验收点 F：新方法应对 B2/B3/B4 提供稳定、可解释的精度收益，B7/B8 和消融应支持证据机制，跨检测器与迁移结果不能出现未解释的严重退化。区间跨零时如实说明不确定性；这些标准是本项目继续推进的依据，不是任何会议的固定分数线。

**第一轮实际执行范围**

如果只能先推进三件事：完成 A01 的连接与路径、完成 B01–B06 的管线修复、完成 C01–C05 的完整基线。这三项决定后续方法研究是否建立在可信输入上。
