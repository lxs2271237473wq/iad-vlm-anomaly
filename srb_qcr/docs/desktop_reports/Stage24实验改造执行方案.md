**Stage 24 实验改造执行方案**

适用项目：iad-vlm-anomaly，审计基准提交 5430d971。资源按单张 RTX 4090 或 A800 规划。本方案是下一轮实验设计；除明确标注的缓存诊断外，下面的新实验尚未执行，也不预设它们一定提升性能。

建议先恢复可信的局部证据与融合增益，再研究选择性调用。保留现有检测器、数据适配器、逐样本日志和候选生成框架；旧 SRB、Quality-QCR 作为基线保留。先暂停制造知识解释、SAM2 refinement、新的大模型及论文语言润色。

**1. 为什么值得继续，但需要改变方法取舍**

当前缓存中的 VisA / PatchCore 宏平均 AUROC：检测器 0.913751，简单融合 0.963056，SRB 0.920229。按类别看，capsules 分别为 0.699500、0.992000、0.719667；pcb1 则为 0.943600、0.850800、0.946800。两类现象同时存在：VLM 可以补充检测器，也可以严重干扰它。下一轮需要保留前者并识别后者。

上述数字只是定位研究机会的缓存诊断。它们受旧代码、归一化和评测问题影响，应在修复后核实；不能据此挑选成功类别作为最终测试。

提示：MVTec重新训练代码中的same_as_test与默认后处理应在实际Anomalib版本检查。仅仅关闭最终F1报告，不能排除上游分数已使用验证标签归一化的可能性。

**3. Stage 24-B 首轮只跑这六组，先看视觉语言证据是否有用**

初始固定PatchCore和现有CLIP ViT-B/32，不同时更换检测器和VLM。固定top-3候选；原有异常图97%分位数与面积过滤先作为旧参数保留，只有坐标/后处理等错误必须立即修正。

| 编号 | 实验 | 输入/方法 | 回答的问题 |
|---|---|---|---|
| B0 | Detector | 修复后的原始检测器分数及独立校准 | 强基线到底是多少？ |
| B1 | Full CLIP | 整图、固定二分类提示 | 定位是否必要？ |
| B2 | Correct crop CLIP | 正确映射到原图的top-3 ROI；保持原聚合规则 | 修复裁剪后，局部证据是否改善？ |
| B3 | Context crop CLIP | 同一ROI中心和候选数，宽高各扩大1.5倍并裁至边界 | 局部语义是否需要更多上下文？ |
| B4 | Detector + B2 | S=(1−α)D+αM；α仅在源域开发折选择 | 无复杂门控时是否存在融合增益？ |
| B5 | Detector + B3 | 与B4使用相同选参规则 | 上下文改善是否能转化为最终检测增益？ |

只在源域开发阶段评估α网格：0、0.05、0.10、0.20、0.35、0.50、0.75、1.00。包含0和1，分别允许检测器与VLM成为退化解。枚举在已缓存的分数上进行，不增加GPU推理。不得在每个目标类别上选择其最优α，然后作为冻结迁移结果。

首轮输出逐类别AUROC/AP、宏平均、逐样本原始分数、图像ID及样本量。最佳F1只能作为诊断；部署F1必须采用独立冻结阈值。

进入下一阶段的条件：修复后的B4/B5能够在源域折外验证上保留可解释的互补收益，而且收益不完全来自明显较弱或失配的检测器。若只在某一个类别出现提升，先定位原因，不扩大主张。

如果B4/B5没有收益，按顺序检查裁剪是否覆盖缺陷、原图高频细节是否被缩放破坏、提示是否错配、分数校准是否失配、检测器基线是否正常。仍无互补性时，再进入下一项条件实验，不继续给门控增加公式。

**4. Stage 24-C 条件性增强语义分支，一次只改一个因素**

只有B阶段证明输入或语义分支不足时才执行：

1. 保持检测器固定，替换一个更强视觉语言编码器，输入信息、提示和候选规则保持一致。若改善来自模型规模，先如实报告为基线增强。
2. 测试正常参考是否能消除纹理/背景误判：参考仅来自允许使用的正常训练集合，禁止从测试集中挑“看起来正常”的样本。参考数量和检索成本固定。
3. 同时加入不用语言的视觉参考匹配分数，确保收益不是单纯来自额外正常图像或更好的视觉特征。

正常参考、局部匹配及更大的CLIP本身都不是预设创新点。此阶段只为建立一个有真实互补性的复核分支。4090先小批量运行，A800用于更高吞吐或较大模型；无需先上生成式大模型。

**5. Stage 24-D 将“高质量/一致才融合”改为“预计有益才复核”**

最小建议模型：一个在源域训练的轻量收益估计器，加一个固定融合器。不先增加复杂网络，不默认保留旧的Q×agreement乘积。

流程：检测器及廉价候选特征 → 预期复核收益u → 预算内选择 → 对选中图运行VLM → 固定α融合；未选图严格保留D。

预门控可用的特征必须在VLM执行之前得到，例如：

- 检测器分数相对独立正常校准分布的位置。
- 异常图峰值、区域/背景对比、响应集中程度和候选面积比例。
- 对同一异常图使用几个预设阈值后，候选位置/面积的稳定性；这不要求额外模型前向。
- 如果已有多层或多尺度检测特征，使用其空间一致性，并将额外计算计入成本。

CLIP自身的margin、prompt一致性、D与M的分歧需要先算M，只能作为复核之后的特征，不能用来声称节省首次VLM调用。

在源域上产生折外D与融合预测，定义复核收益。例如，在经过独立校准的概率上，u=loss(D,y)−loss(F,y)，正值表示融合更好。概率校准、融合α和门控都要分开拟合，外层留出的类别不参加训练或选择。类别留一的内层校准用于避免同一批标签同时选择所有组件。

训练一个简单回归器估计u；样本少时优先低容量线性/树模型。按预计收益或收益/成本选择样本，阈值仅在源域内部确定，并与相同预算的简单选择器比较。

若采用此方案，准确表述是“无目标域异常监督”，因为源域异常标签参与了收益学习。不能再称整个方法完全训练自由。如果坚持不训练门控，先固定廉价代理和预算规则，用同样实验验证，不能依据目标成绩反复调整Q方向。

拒绝继续该模块的条件：同预算下不能超过固定小权重或简单不确定性选择；门控只是在检测器已经正确的样本上重复确认；收益在换一个宿主检测器后消失且没有可解释机制。

**6. Stage 24-E 必须有的最终消融矩阵**

| 要隔离的因素 | 比较方式 |
|---|---|
| 选择哪张图 | 同预算随机、检测器不确定性、仅Q、预测收益 |
| 选中后怎么融合 | 同一gate下固定α、仅Q权重、仅agreement、旧SRB |
| 是否需要语言 | 相同正常参考和视觉特征下，视觉匹配复核vs视觉语言复核 |
| 是否能泛化 | 同一冻结规则应用于第二个检测器和新的独立测试 |
| 是否真的省计算 | 相同实现的全量VLM与选择性VLM；detector-only作为零调用基线 |

先做25%、50%、75%调用预算，最终补0%、10%、100%形成曲线。这里是调用比例，不是节省比例。不同图像crop数不同，应同时比较crop编码数与实际耗时；跨模型比较还必须考虑每次调用成本。

在批处理设置中，可按得分排序选择固定数量样本实现严格同预算，并明确允许看完整批次的廉价特征。在线部署则使用源域确定的固定阈值，报告目标实际调用比例；不能在目标上重新调阈值凑出预定调用率后仍称严格在线冻结。

随机门控使用多个固定种子，在源域预设重复次数。其他超参数不得为目标单独重选。

每组报告四种决策情况：检测器对/VLM对、检测器对/VLM错、检测器错/VLM对、两者都错。正误基于独立冻结阈值，不直接使用未校准分数0.5。并报告门控接受率、净纠错数、新引入错误、错失纠错机会。AUROC路线还可以检查正负样本对的排序改善与破坏，这些是回顾性诊断，不能用目标标签实现门控。

**7. Stage 24-F 数据划分与最终验证**

VisA作为源域开发，采用外层类别留一、内层校准/选参。目标正常数据如被用于训练检测器或校准，明确标明normal-only adaptation，不把整条系统表述成对目标完全无适配。

已反复查看的MVTec AD与AD2四类用于修复确认及已知目标压力测试。完整AD2公开八类有助于覆盖场景，但其中真正未用于设计的部分必须通过历史记录确认。最终再保留未参与任何方法开发的数据/类别或适配任务的官方隐藏评测；若新增逻辑异常数据，则额外验证局部候选覆盖假设，不能默认沿用。

按物件/场景分组防止多视角、多光照图泄漏。全部主方法与基线共用manifest。AnomalyCLIP等外部基线应在同一图像集合和明确监督制度下运行，不能把484图与243图结果合并排序。

统计主指标预先固定为逐类别macro AUROC，pooled单列；配对置信区间与点估计采用同一聚合方式。若研究部署，补固定正常误报预算下的召回和对应区间，误报预算根据独立正常校准集的样本量确定，不能在样本不足时声称可靠估计极低FPR。

推理时延包括检测器、候选、门控、VLM和融合；校准/模型加载等一次性成本另列。报告合理批处理下的吞吐和逐图延迟，使用同一执行输出验证准确率与时间。缓存回放不能作为冷启动选择性部署证明。

**8. 第一轮应交付的东西与后续决定**

第一轮只交付：一个修复后的统一推理入口、一份冻结数据清单、六组B阶段结果、同一批输入的ROI叠加审计图，以及一张逐类别增益/损害表。

据此选择后续动作：

- B4/B5增益稳定，旧SRB压制收益：推进收益门控，保留旧SRB作对照。
- 增益在正确裁剪后消失：回查原结论，不延续旧缓存叙事。
- VLM仍弱而更强视觉复核器有效：转向有依据的视觉复核研究，或限定语言分支只承担经评测的语义任务。
- 简单融合已经与复杂方法相当：先把简单方法建立为强基线，只有新机制能够解释并解决其具体失败时再继续。

不要预设“必须涨几个点”或“增加模块就够CCF B”。先让每一轮实验决定下一步投入，最终贡献应来自可复现、同预算、独立验证的证据。
