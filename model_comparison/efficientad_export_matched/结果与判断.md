# EfficientAD 旧权重逐图推理及互补审计

2026-09-15。仅加载既有100轮权重推理，没有训练、没有恢复模型库队列。

## 可复现性核对

四类原始public共484张，139正常、345异常，全部逐图分数已导出。原Folder测试目录图像通过SHA256映射到原始AD2图像，再通过Stage24 manifest映射image_id，484张完全且唯一对齐PatchCore512与DINOv2。

从历史测试可视化文件名恢复实际测试243张：fruit_jelly40、sheet_metal57、vial71、walnuts75，70正常、173异常。后处理AUROC分别为82.6667%、70.8333%、90.3564%、62.4074%，宏平均76.5660%，与历史100轮结果吻合（浮点精度误差以内）。

首次采用导出模块预处理时结果偏离：导出Resize为antialias=False，而历史测试回调transform为antialias=True。最终采用测试回调transform及16-mixed对应的CUDA float16 autocast。第一版仅保留排错，不用于结论。后处理会截断分数产生并列，因此互补主表用原始连续分数；同时保存后处理分数用于历史复现。

完整484张包括旧测试以外的图像，可能参与过历史验证/校准，不能当独立未见测试。因此以243张历史实际测试子集作主要诊断，484张只作补充。所有操作点为每类测试ROC首个召回>=95%的阈值，不是部署阈值；公开集已反复用于开发，不作显著性或盲测声明。

## 484张补充诊断

PatchCore512：FP95/FN16；EfficientAD纠正20个FP、找回16个FN、误伤16个TP、新增22个FP，共同FP75、共同FN0。

AND：FP75/FN32，FPR53.96%，召回90.72%；OR：FP117/FN0，FPR84.17%，召回100%。同样显示漏报互补，但误报否决代价明显。

## 决策

1. 不建议直接用EfficientAD否决PatchCore报警；并未优于DINO分支的误报纠正/误伤权衡，且收益集中vial。
2. 保留“低漏报候选并集→局部证据复核”的研究线索，因为两种机制的漏报集合在当前样本不重合。并集只是候选入口，不是完成的方法，仍需解决大量共同误报。
3. 下一步应检查38个共同FP与14个异常分歧样本（两方向各7），看异常区域响应、正常参考、尺度信息能否解释分歧。不能用真实标签充当门控，也不能按目标类别选择模型。
4. 暂无新方法精度提升或论文创新成立的证据；先验证可观察的局部判别证据是否存在，再决定是否值得训练选择器。
5. 仅覆盖已有权重的四类；can、wallplugs等未获得EfficientAD互补结论。
