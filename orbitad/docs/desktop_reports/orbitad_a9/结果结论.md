# A9结果：停止当前周边检索方案

8类异常图生成和1084张public图的自动评估均完成。生成阶段COMPLETE.json中的evaluation_pending=true是静态旧标记，评估日志和diagnostic512_summary.json证实评估已完成。

指标是512诊断网格AU-PRO@0.05，先逐类平均该类可用条件，再对8类宏平均。不是图像AUROC，也不是原生GT评估。不能直接与以前shift1/2/3的0.2774比较。

|方法|全条件宏平均|
|---|---:|
|原始NN|0.216329|
|PCA16|0.275881|
|周边top1检索、中心评分|0.141810|
|周边top8检索、中心最小距离|0.150447|
|中心top8取最小距离（恒等校验）|0.216329|

周边top8相对PCA下降0.125433，即12.54个百分点；8/8类均低于PCA。周边top1仅fruit_jelly超过PCA，不能以此事后挑类别继续包装。

参考中心库与旧库8类最大绝对误差均为0；原始NN与中心top8-min结果相同，符合数学预期。生成用时合计约57.4分钟（不含初始化和自动评估）。这些检查排除明显参考样本变动及恒等对照错误，但不是所有实现与建模假设均已被验证。

结论：5×5周边平均描述直接筛选中心参考的当前实现不具竞争力，停止该版本；不能据此声称所有上下文方法无效。周边相似未必意味着中心应该相似，是一种待验证解释，尚未通过参考可视化证实。

本轮没有微小缺陷分组召回和误报来源标注，不能声称已单独证明微小缺陷方案失败。全局大幅退化足以停止其主线，无需继续为此版本扩大实验。

下一优先级：保留PCA16，转向相同预算下的高分辨率证据保留；先做全图与覆盖式切片的受控比较，再判断是否值得开发自适应计算。不得将完整高分辨率地图离线替换实验当成实际推理加速。成熟方法适配只作为基线，不计作创新。

未在本轮启动下一实验，也没有修改旧实验结果。
