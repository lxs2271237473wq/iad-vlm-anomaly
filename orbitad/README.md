# OrbitAD：AD2 创新主线

OrbitAD 汇总基于 AD2 的创新探索。研究从正常采集变化建模出发，经过多层近邻记忆、局部残差和分辨率互补实验，当前收敛到“共享记忆库 + 全局/局部双分支 + 正常尺度校准”的候选方案。

## 阶段划分

| 阶段 | 实验编号 | 目标 | 结论定位 |
|---|---|---|---|
| 数据与正常变化审计 | A0–A2 | 条件配对、低频变化、反事实持续性 | 解释问题来源 |
| 表征与机制探索 | A3–A8 | 多分辨率记忆、OCC、正常子空间、关系表征 | 多条路线未形成稳定主增益 |
| 多层强基线 | A9–A11 | 上下文参考、多层特征、固定融合 | 建立后续比较起点 |
| 跨分辨率与路由 | A12–A18 | 缓存多尺度、尺寸分组、正常路由、状态记忆 | 证明互补存在但路由不稳定 |
| 组件互补审计 | A45–A66 | 全局/局部组件、迁移、残差融合与因子审计 | 局部增益依赖类别和协议 |
| 正常校准候选 | A67–A72 | 正常图统计、q99 尺度融合、Cable 迁移 | A72 为初步正结果；AD2 主结果需修复协议 |
| 跨类验证 | A73 | MVTec 多类别 448/672 双分支 | 结果完成后再作最终判断 |

## 当前代码入口

- `scripts/`：A0–A18 的历史实验脚本。
- `scripts/current/`：A45–A73 当前主线的生成、评估、消融和启动脚本。
- `docs/desktop_reports/`：方法审计与路线报告。
- `studies/`：早期阶段导航；轻量结果摘要按 `.gitignore` 白名单保存。

当前候选方法、证据限制和修复要求见仓库根目录的 [`docs/CURRENT_STATUS.md`](../docs/CURRENT_STATUS.md)。

## 运行约定

历史脚本包含服务器绝对路径，默认项目根目录为 `/root/private_data/iad-vlm-anomaly`。迁移到其他机器前应统一改为命令行参数或环境变量。数据、权重、外部 SuperAD/DINOv2 源码、特征缓存和 TIFF 预测图不在仓库中。

不要把 A69/A70 的 `0.602419` 作为已修复主结果：七个类别的全局测试图与正常校准图来自不同分辨率协议。修复应产生新的实验编号和完整配置指纹，不能覆盖旧结果。
