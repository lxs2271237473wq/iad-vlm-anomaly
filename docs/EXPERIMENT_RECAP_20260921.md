# iad-vlm-anomaly 全实验成果复盘（截至2026-09-21）

本轮回查早期SRB/QCR、Stage24、Stage25、OrbitAD A0–A74、模型互补表以及最新审计。依据为本地归档CSV/JSON、服务器阶段结果及协议。没有重新训练，也没有把完成标记等同于方法成功。

## 一、成果与创新的分级

- **已有实证支持的设计规律**：空间采样密度影响微小缺陷检测；特征深度存在缺陷尺寸偏好；不同分支/检测器有条件互补，融合的收益取决于是否破坏强分支。
- **有正结果的方法候选**：L5正常尾概率融合、A54小幅尺度对齐残差、预算受限的高分辨率局部查询、A73/A74固定双尺度均值。
- **尚未成立的主张**：一个新融合器在多数据集上稳定超过最强单分支和朴素融合；VLM稳定降FP且不增FN；通用正常校准；已达到CCF B投稿的完整证据标准。

这里的“有实证支持”是项目内的机制与结果判断，不代表这些机制相对公开文献已证明新颖。本轮没有进行新的完整文献排重。

### 4. A27/A32及A34/A36：正常尾概率校准NTDF

NTDF使用正常经验尾概率变换后融合。它不同于A69/A74的q99除法，也不同于A74的q95/q99线性tail_mean。

L5版本：

- AD2总体：等权0.473239 → NTDF 0.480989；差值+0.007751，CI [0.000768, 0.016130]。
- AD2 tiny：0.404832 → 0.414645。
- MVTec tiny：0.707476 → 0.737930；+0.030454，9/13类提高，CI [0.007338, 0.062493]。
- MVTec总体：0.758264 → 0.754765，反而下降0.003500。

**可保留的限定正结论**：特定L5深度融合组合中，正常尾概率校准相对等权融合改善tiny定位。它没有普遍提高总体指标；MVTec L5单支tiny为0.749241，仍高于NTDF。改为L8后，NTDF在AD2提高0.006877，但MVTec总体相对等权下降0.009293。

因此这是一项有价值的子问题候选，不能宣布“通用校准创新已经验证”。

依据：`outputs/orbitad_final/证据链阶段结论_A27_A32.md`；`outputs/orbitad_a32/size_stability_vs_equal.json`；服务器A34/A36。

## 三、FP/FN研究已取得的事实

在正常validation/good q95固定阈值下，PatchCore512：TP313、FN392、FP70、TN309，图像FPR18.47%、FNR55.60%。它明确证明单纯调高阈值无法解决高召回低误报需求。

EfficientAD旧权重已完成四类484图导出，并在真实历史243图子集复现宏图像AUROC0.765660。其与PatchCore在高召回诊断点：纠正9个FP、找回7个FN，同时误伤7个TP、新增11个FP；共享38/47个PatchCore误报。

这是错误互补与代价的实证，不是一个能在测试前选对分支的算法。VLM、硬AND/OR和普通平均尚未被证明可以维持召回并稳定降低FP。

## 六、当前最值得保留的论文材料

1. **机制证据**：深度×分辨率影响不同尺寸缺陷，固定高分辨率局部查询可以在现有显存预算下运行。
2. **候选方法证据**：A54低幅融合、L5 NTDF的tiny收益；都必须保留最强单支和普通融合对照。
3. **问题定义证据**：正常局部干扰、共同误报、高召回代价和多光照场景相关性。
4. **复现实证**：强基线、负实验、公开开发/冻结迁移/私有最终评测的边界。

下一步应先修正评价与坐标/掩膜问题，然后在同实现下对比最强单支与候选模块。值得追踪的研究问题是“如何根据正常数据判断局部证据的可靠性，在保留高分辨率收益时避免损伤强分支”；目前尚无已通过独立验证的可靠性选择器，不能把它提前写成完成的贡献。
