# 实验地图与目录说明

## 1. 整体研究故事

项目最初尝试把传统异常检测器与 VLM/QCR/SRB 进行分数融合，希望通过语义判断降低误报。已有结果表明，复杂融合并未稳定超过朴素融合，且 AD2 上常规检测器已经较强，因此研究问题转向更具体的失败模式：微小缺陷在下采样后丢失，而高分辨率局部纹理又容易把正常结构放大成异常。

Stage24 检查了多尺度、局部表征、参考检索和证据融合；Stage25 对微小缺陷、裁剪控制、浅层局部特征与跨数据集迁移进行了专项分析。OrbitAD 随后系统测试正常变化子空间、关系表征、多层记忆、分辨率路由和双分支融合。当前候选是冻结多层特征上的全局/局部双分支，并用正常图的高分位尺度校准两张异常图。

## 3. 当前方法的数据流

1. 从每类正常训练图提取冻结 DINOv2 的多层 CLS 表征，通过 coreset 选择 16 张参考图。
2. 对参考图提取第 6、12、18、24 层 patch token，分别归一化并建立四个最近邻记忆库。
3. 全局分支将完整查询图按短边 448 输入；每层执行 `1 - max cosine similarity`，恢复空间网格后平均为 `G`。
4. 局部分支按原图短边形成重叠方形窗口，每块缩放到 672，采用相同记忆库推理，再回填原坐标并按覆盖次数平均为 `T`。
5. 正常校准集经过同一检测器，逐图计算 `G` 与 `T` 的 q99；每类跨图取中位数得到 `qG`、`qT`。
6. 测试时得到 `Gn = G/qG`、`Tn = T/qT`，候选融合为 `F = 0.5*(Gn+Tn)`。
7. 真值掩码只用于 AU-PRO、像素 AUROC、固定阈值 FP/FN 和尺寸分组评测，不参与参考选择、裁块或融合。

## 4. 复现实验的建议顺序

1. 阅读 `docs/CURRENT_STATUS.md`，确认哪些结果可用、哪些仅是探索记录。
2. 准备数据与 DINOv2 权重；外部 SuperAD 源码放在被忽略的本地目录。
3. 按 `orbitad/scripts/current/` 中的 A67、A68 建立独立正常校准统计。
4. 使用完全一致的权重、参考清单、预处理、参考分辨率和查询分辨率补生成测试组件图。
5. 运行 q99 均值、未经校准均值、单分支和同计算预算对照。
6. 冻结方法后在未参与选择的类别或数据集上评估，并报告置信区间、FP/FN、运行成本与失败案例。

## 5. 版本与证据规则

- 历史结果不覆盖；修复实验使用新编号和新输出目录。
- 每次实验记录 Git 提交、权重标识、参考图清单、数据划分、预处理、分辨率及随机种子。
- CSV/JSON/Markdown 摘要可以提交；权重、数据集、特征数组、逐图 TIFF/PNG、日志和第三方源码留在本地。
- “运行完成”与“协议正确”分开判断；论文主表只收录配置一致且来源可追溯的结果。
